# Udemy Homepage Clone

A simple one-page Udemy homepage clone built using HTML and CSS.
This project was created to practice front-end web development and improve website layout designing skills.

## Features

* Responsive homepage design
* Navigation bar
* Course sections
* Clean UI layout
* Beginner-friendly project structure

## Technologies Used

* HTML5
* CSS3

## Project Structure


udemy-clone/
│── index.html
│── style.css

## Purpose of the Project

This project was created to:

* Practice HTML and CSS
* Improve front-end development skills
* Learn website cloning techniques
* Understand responsive web layouts
